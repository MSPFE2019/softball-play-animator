Coach cue

1. BallWho gets it?
2. BaseWho covers?
3. ThrowWhere does it go?
4. OutForce or tag?

10U rule of thumb

Get one sure out. If the throw is not clean, hold the ball and stop the next base. Young players learn faster when the decision tree is small.

Built for short practice reps: show the animation, ask the four questions, then run it live on the field.
